# Infrastructure-pme-vmware
Infrastructure virtualisée PME - OPNsense + Windows Server 2022 + AD

Déploiement d'une infrastructure réseau virtualisée complète simulant le système d'information d'une PME de 15 employés, sous **VMware Workstation**.

> **Résultat :** Infrastructure fonctionnelle et sécurisée : chaque employé accède uniquement à ses dossiers autorisés, avec une authentification centralisée.

---

## 🎯 Objectifs

- Sécuriser le réseau de l'entreprise avec un pare-feu
- Centraliser l'authentification avec Active Directory
- Gérer les accès aux fichiers par groupe / service
- Simuler un environnement de production réel en virtualisé
